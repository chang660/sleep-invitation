# 山东睡眠疗愈交流会 · H5 邀请函

## 项目概要

睡眠疗愈交流会 H5 邀请函，6 页全屏滑动交互，森林墨绿主题。

## 技术栈

- 原生 HTML/CSS/JS（轻量无框架）
- Swiper.js 11（垂直滑动 + Parallax 视差）
- Canvas 星空粒子 + 流星特效
- 高德地图 URI 导航
- PWA（可添加到桌面）

## 使用方式

```bash
npx http-server H5邀请函 -p 8080
```

浏览器打开 `http://localhost:8080`

## 自定义修改

- **活动日期**：编辑 `js/main.js` 中 `CONFIG.eventDate`
- **背景音乐**：将 mp3 放入 `assets/background.mp3`
- **地图终点**：修改 `js/main.js` 中 `CONFIG.mapUrl`
- **团队名单**：编辑 `index.html` P5 部分
- **收款二维码**：替换 `assets/payment-qr.png` 为你的微信/支付宝 99 元收款码
- **WPS 表单链接**：编辑 `index.html` 中 `wpsLink` 的 `href`
- **颜色主题**：主色 `#192823`，修改 `css/style.css` 中的颜色值
